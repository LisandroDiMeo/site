# Deployment

## Modes

The site supports two deployment modes controlled by environment variables:

| | Local | Cloud (Cloudflare Pages) |
|---|---|---|
| Posts API | Enabled (localhost:8090) | Disabled |
| Photos | Filesystem or external NAS | External NAS only |
| Config file | `.env` | `.env.production` |
| Build command | `npm run build:local` | `npm run build:production` |

## Environment Variables

### Local (`.env`)

```
VITE_APP_TITLE=Lisandro's Site
VITE_DEPLOYMENT_TYPE=local
VITE_API_BASE_URL=http://localhost:8090
VITE_PHOTOS_MODE=filesystem
VITE_LOCAL_PHOTOS_PATH=/assets/photos
VITE_EXTERNAL_PHOTOS_URL=https://sarusage.myasustor.com/photos
```

### Production (`.env.production`)

```
VITE_APP_TITLE=Lisandro's Site
VITE_DEPLOYMENT_TYPE=cloud
VITE_API_BASE_URL=
VITE_PHOTOS_MODE=static
VITE_LOCAL_PHOTOS_PATH=/assets/photos
VITE_BASE_URL=/
VITE_EXTERNAL_PHOTOS_URL=https://sarusage.myasustor.com/photos
```

In cloud mode, the posts API is disabled (no `VITE_API_BASE_URL`), and photos are served from the external NAS URL.

## Vite Configuration

- Dev server runs on port 3000
- API proxy: `/api` requests forwarded to `http://localhost:8090`
- Allowed hosts: `localhost:3000`, `eldiem.xyz`
- Production build outputs hashed assets to `dist/`

## Cloudflare Pages

Static files in `public/` include Cloudflare-specific configuration:

- `_headers` — HTTP header rules
- `_redirects` — URL redirect rules

## NPM Scripts

| Command | Description |
|---------|-------------|
| `npm run dev` | Start dev server (port 3000) |
| `npm run dev:local` | Dev server with local env |
| `npm run build` | Production build |
| `npm run build:local` | Build with local env |
| `npm run build:production` | Build for Cloudflare Pages |
| `npm run preview` | Preview production build |
| `npm run lint` | ESLint with auto-fix |

## Photo Index Generation

The photo gallery relies on `public/photo-index.json`, generated by a Python script that indexes photos from a NAS via SSH/SFTP.

```bash
python generate-photo-directory.py \
  --user <ssh_user> \
  --password <ssh_password> \
  --host <nas_ip> \
  --remote-path <photo_directory>
```

- Connects via Paramiko SSH/SFTP
- Recursively scans for images (.jpg, .jpeg, .png, .gif, .webp, .bmp, .svg)
- Respects exclusions in `public/dont-show.json` (filtered files and directories)
- Collects file metadata: name, size, modified/created timestamps
- Outputs nested JSON with paths, files, file details, subdirectories, and photo counts
